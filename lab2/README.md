# Feedback Bot — Lab2

Telegram-бот для сбора обратной связи после обучения сотрудников и работы с каталогом обучений из CSV.

## Что добавлено в Lab2

Во второй лабораторной бот подключён к файлу `trainings.csv`.

Новые возможности:

- `/trainings` — показать все обучения из CSV;
- `/training <запрос>` — найти обучение по части названия без учёта регистра;
- `/department <отдел>` — показать обучения выбранного подразделения;
- понятные сообщения при отсутствии файла, пустом CSV, неправильных столбцах и некорректных строках.

Существующий функционал Lab1 сохранён: сбор отзывов, SQLite, уведомления руководителю и отчёт.

## Команды

- `/start` — описание бота и список команд
- `/help` — помощь
- `/feedback` — оставить отзыв
- `/skip` — пропустить комментарий
- `/cancel` — отменить заполнение
- `/report` — посмотреть отчёт, доступно только руководителю
- `/myid` — показать свой Telegram ID
- `/trainings` — показать весь каталог обучений
- `/training адаптация` — найти обучение по названию
- `/department HR` — показать обучения подразделения

## Структура trainings.csv

```csv
name,department,format,date,owner
Адаптация новых сотрудников,HR,Онлайн,2026-10-10,Анна Смирнова
```

Обязательные столбцы:

- `name` — название обучения;
- `department` — подразделение;
- `format` — формат обучения;
- `date` — дата в формате `YYYY-MM-DD`;
- `owner` — ответственный.

## Требования

- Python 3.9+
- python-telegram-bot 21.11.1
- python-dotenv 1.1.1

Для CSV используется стандартный модуль `csv`, поэтому дополнительные библиотеки не нужны.

## Установка

Создать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Создать `.env` на основе `.env.example`:

```text
BOT_TOKEN=ваш_токен
ADMIN_ID=ваш_telegram_id
```

## Запуск

```bash
python bot.py
```

После запуска открыть бота в Telegram и отправить `/start`.

## Обработка ошибок CSV

Бот не завершает работу, если:

- `trainings.csv` отсутствует;
- файл пустой;
- отсутствуют обязательные столбцы;
- строка содержит пустые обязательные поля;
- дата имеет неправильный формат;
- файл невозможно прочитать.

Вместо падения бот отправляет пользователю понятное сообщение.

## Хранение отзывов

Отзывы по-прежнему сохраняются в SQLite (`feedback.db`). Файл базы исключён из Git.

## Безопасность

Настоящий токен хранится только в `.env`. Файл `.env` и локальная база данных исключены через `.gitignore`.
