Улучши моего существующего Telegram-бота на Python, добавив работу с CSV-файлом.

Текущий функционал бота:
- /start и /help показывают назначение и команды;
- /feedback запускает сбор обратной связи после обучения;
- пользователь указывает название обучения, оценку от 1 до 5 и комментарий;
- /skip позволяет пропустить комментарий;
- /cancel отменяет незавершённый отзыв;
- отзывы сохраняются в SQLite;
- после сохранения руководитель получает уведомление;
- /report доступен руководителю и показывает статистику по отзывам;
- /myid показывает Telegram ID для настройки ADMIN_ID.

Новый источник данных:
CSV-файл trainings.csv.

Структура файла:
name,department,format,date,owner

Поля:
- name — название обучения;
- department — подразделение;
- format — формат обучения;
- date — дата проведения в формате YYYY-MM-DD;
- owner — ответственный за обучение.

Новый функционал:

1. Добавить команду /trainings.
Она должна читать trainings.csv и выводить список всех доступных обучений.

Для каждого обучения показать:
- название;
- подразделение;
- формат;
- дату;
- ответственного.

2. Добавить команду /training <запрос>.
Она должна искать обучение по названию без учёта регистра.
Допускается частичное совпадение.

Пример:
/training адаптация

Бот должен вывести найденное обучение в понятном формате.
Если найдено несколько вариантов — показать все.

3. Добавить команду /department <название отдела>.
Она должна выводить все обучения указанного подразделения без учёта регистра.

Пример:
/department HR

4. Если пользователь не передал текст после /training или /department,
бот должен показать понятный пример использования команды.

5. Если обучение или подразделение не найдено,
бот должен сообщить об этом без ошибки.

6. Добавить обработку ошибок при работе с CSV:
- файл отсутствует;
- файл пустой;
- отсутствуют необходимые столбцы;
- некорректная строка данных.

При проблеме бот должен показать пользователю понятное сообщение,
а не завершать работу.

Технические требования:
- сохранить весь существующий функционал Lab1;
- использовать стандартный модуль csv из Python, без pandas;
- CSV должен читаться из файла trainings.csv;
- код должен оставаться простым и понятным;
- добавить комментарии на русском языке;
- не хранить токен в коде;
- BOT_TOKEN и ADMIN_ID по-прежнему брать из .env;
- существующая SQLite-база отзывов должна продолжить работать;
- новые команды добавить в /start и /help.

1. обновлённый bot.py;
