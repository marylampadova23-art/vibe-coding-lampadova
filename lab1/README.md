# Feedback Bot

Telegram-бот для сбора обратной связи после обучения сотрудников.

## Возможности

Бот умеет:

- собирать название обучения;
- принимать оценку от 1 до 5;
- сохранять комментарий или пропускать его;
- отменять незавершённый отзыв;
- хранить данные в SQLite;
- отправлять уведомление руководителю о новом отзыве;
- формировать сводный отчёт по отзывам;
- показывать пользователю его Telegram ID.

## Команды

- `/start` — описание бота и список команд
- `/help` — помощь
- `/feedback` — оставить отзыв
- `/skip` — пропустить комментарий
- `/cancel` — отменить заполнение
- `/report` — посмотреть отчёт, доступно только руководителю
- `/myid` — показать свой Telegram ID

## Требования

- Python 3.9
- python-telegram-bot 21.11.1
- python-dotenv 1.1.1

## Установка

Создать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate

Создать файл `.env` на основе `.env.example`:

BOT_TOKEN=ваш_токен
ADMIN_ID=ваш_telegram_id

## Запуск

python bot.py

После запуска открыть бота в Telegram и отправить:

/start

## Хранение данных

Отзывы сохраняются в SQLite-базе данных.

В базу записываются:

- номер отзыва;
- название обучения;
- оценка;
- комментарий;
- дата и время.

Имена, username и Telegram ID участников отзывов не сохраняются.

## Безопасность

Настоящий токен хранится только в `.env`.

Файл `.env` исключён из Git через `.gitignore`.
