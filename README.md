# Vibe Coding — Лампадова Мария

Репозиторий для лабораторных работ по курсу Vibe Coding for Business.

## Структура

- `lab1` — Telegram-бот для сбора обратной связи после обучения
- `lab2` — подключение бота к CSV-файлу с каталогом обучений
- `lab3` — облачный деплой Telegram-бота и тестирование с реальными пользователями

## Lab1

В первой лабораторной работе был создан Telegram-бот, который:

- собирает оценки и комментарии после обучения;
- сохраняет отзывы в SQLite;
- отправляет уведомление руководителю;
- формирует сводный отчёт по отзывам.

Отчёт находится в:

`lab1/report/report.md`

## Lab2

Во второй лабораторной работе бот был подключён к внешнему источнику данных — CSV-файлу `trainings.csv`.

Добавлены команды:

- `/trainings` — показать все обучения;
- `/training <запрос>` — найти обучение по названию;
- `/department <отдел>` — отфильтровать обучения по подразделению.

Также реализована обработка ошибок при чтении CSV.

Отчёт находится в:

`lab2/report/report.md`

## Lab3

В третьей лабораторной работе бот подготавливается к облачному развертыванию и реальному использованию.

Основные задачи:

- развернуть бота в облаке;
- настроить безопасное хранение переменных окружения;
- обеспечить постоянное хранение SQLite-базы;
- проверить стабильность работы;
- собрать обратную связь от пользователей;
- внести улучшения на основе полученного фидбека.

Отчёт будет находиться в:

`lab3/report/report.md`
